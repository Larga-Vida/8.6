### git操作顺序

1. init：初始化本地仓库
2. add：将修改后的文件加入暂存区
3. commit：提交暂存区改动
4. branch：创建分支
5. merge：合并分支功能到主分支
6. push：将提交内容推送至GitHub远程仓库

### 表格

|git命令|作用|使用场景|
|:--:|:--:|:--:|
|git checkout -b feature‑blink |创建新分支并且立刻进入该分支|在不影响主分支的情况下研究一个新的内容如代码块|
|git merge feature‑blink |将分支及其功能合并到主分支|分支部分调试完成，需要将其功能合并到主分支里|

### 代码块

```
git checkout -b feature-blink # 新建并且跳转至分支

git add Core/Src/main.c
git commit -m "调整LED闪烁次数为60次，修改闪烁延时" # 修改main.c里面代码并在分支内提交

git checkout main # 切回main主分支

git merge feature-blink # 合并分支到主分支
```
